# 🃏 斗地主 - 局域网联机对战

> 标准3人斗地主游戏，支持局域网多人实时联机对战。主电脑运行服务端，其他玩家通过浏览器即可加入游戏。

## 📋 系统要求

| 要求 | 说明 |
|------|------|
| 操作系统 | Windows 10/11, macOS, Linux |
| Node.js | v18 或更高版本 |
| 浏览器 | Chrome 90+, Edge 90+, Firefox 90+（推荐Chrome） |
| 网络 | 所有玩家需在同一局域网内 |

## 🚀 快速开始（2步）

### 第一步：安装依赖

```bash
# 在项目根目录安装服务端依赖
npm install

# 进入客户端目录安装前端依赖
cd client
npm install
cd ..
```

### 第二步：启动游戏

```bash
# 生产模式（推荐）
npm run build    # 先构建客户端
npm start        # 启动服务端
```

启动后会显示：
```
═══════════════════════════════════════════
  🃏  联机斗地主游戏服务端已启动！
═══════════════════════════════════════════
  本地访问:  http://localhost:3000
  局域网访问: http://192.168.x.x:3000
═══════════════════════════════════════════
```

**开发模式**（支持热更新）：
```bash
# 终端1：启动服务端
node server/index.js

# 终端2：启动客户端开发服务器
cd client && npm run dev
# 访问 http://localhost:5173
```

## 🎮 游戏玩法

### 基本流程
1. **打开游戏** → 主机启动服务端后，所有玩家在浏览器打开局域网地址
2. **登录** → 可选注册账号、账号登录或游客体验
3. **创建/加入房间** → 一人创建房间，其他人输入房间号加入
4. **准备** → 3名玩家都点击「准备」后自动开始
5. **抢地主** → 依次选择「抢地主」或「不抢」
6. **加倍** → 可选手动加倍或跳过
7. **出牌** → 地主先出，轮流压牌或不出
8. **结算** → 最先出完手牌的一方获胜

### 牌型一览

| 牌型 | 要求 | 示例 |
|------|------|------|
| 单张 | 1张 | ♠3 |
| 对子 | 2张相同 | ♥5 ♦5 |
| 三张 | 3张相同 | ♠K ♥K ♦K |
| 三带一 | 3张相同 + 1张 | ♠Q ♥Q ♦Q + ♣7 |
| 三带对 | 3张相同 + 1对 | ♠J ♥J ♦J + ♣4 ♦4 |
| 顺子 | 5张+连续(3-A) | 34567 |
| 连对 | 3对+连续(3-A) | 334455 |
| 飞机 | 2组+连续三张 | 333444（可带单/对） |
| 炸弹 | 4张相同 | ♠8 ♥8 ♦8 ♣8 |
| 王炸 | 大王+小王 | 最大牌型！ |

### 牌力排序
```
大王 > 小王 > 2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3
```

### 倍数规则
- 基础倍数 = 叫地主轮次（1-3倍）
- 每个「加倍」×2
- 每个「炸弹」×2
- 每个「王炸」×4

## 🎨 技术特点

- **零图片依赖**：54张扑克牌纯CSS绘制，无任何图片资源
- **零音频文件**：所有音效通过Web Audio API实时合成
- **服务端权威**：所有游戏逻辑在服务端执行，防作弊
- **自动重连**：断线自动重连，异常状态优雅处理
- **SQLite存储**：零配置数据库，开箱即用

## 🔧 常见问题

### 1. 其他玩家无法连接？
- 确认所有玩家在同一局域网（连同一个WiFi）
- 检查防火墙是否阻止了3000端口
- 使用启动时显示的「局域网访问」地址

### 2. Node.js 环境配置？
- 下载安装 Node.js: https://nodejs.org/ （推荐v18 LTS）
- 安装后重新打开终端，运行 `node --version` 验证

### 3. 端口被占用？
- 修改 `server/config.js` 中的 PORT
- 或设置环境变量：`PORT=3001 npm start`

### 4. 数据库在哪里？
- 自动创建在 `server/data/poker.db`
- 删除此文件可重置所有玩家数据

## 📝 开发说明

- 代码使用 ES Modules，Node.js 需要设置 `"type": "module"`
- 服务端使用 Express + Socket.io，提供 RESTful WebSocket 双通道
- 客户端使用 React 18 + Vite 5 + Zustand
- 共享代码在 `shared/` 目录，服务端和客户端共同引用
- 所有核心代码附有详细中文注释
